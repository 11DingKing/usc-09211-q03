# 航天家书接力站领域约定

服务采用事件时间与接收时间分离的记录方式。所有业务身份由调用方提供的稳定标识表示，审计记录不得以覆盖方式修改。

## 核心概念

- **统一凭据**：信件一经收件即获得 `letter_id` 与收件确认（含幂等判定），
  后续授权、复核、封存、回执、展示全部以 `letter_id` 串联，并写入同一条
  哈希链审计，形成可全程追溯、不可覆盖的统一凭据。
- **匿名化收件**：导入时直接身份（姓名、学校、监护人）加密存入保险库
  （`identities`），业务流转只使用系统生成的匿名标识 `pseudonym`；
  信件正文加密存储，业务查询不返回原文。
- **监护授权（consent）**：按范围（`uplink` 上行 / `display` 展示）授予，
  带 `valid_from`/`valid_until` 有效期；撤回按接收时间生效并同步传播——
  候选池与开放批次即时移除，已封存批次以增量更正（`remove`）登记，
  未来展示在校验时被拒，早于撤回时刻的历史展示快照仍然成立。
- **双人复核**：两名不同复核人各投一票方可通过；导入人不得复核自己导入的
  信件；涉及未成年人内容，一票否决即终止。
- **批次封存**：分块推进并写入 `seal_journal`（封存计划、进度、评估时点），
  崩溃后重启自动从断点续跑；封存清单一经提交不可修改，只能追加增量更正。
- **回执对账**：以封存清单 + 增量更正为应发口径，对照回执给出
  已发/缺失/失败/异常（从未入批）/被更正取代 五类结果。
- **展示快照证明**：每次公开展示锚定一份授权快照（内容哈希即快照 ID，
  并写入审计链），任何一方都可重算验证“该次展示对应当时有效的授权”。
- **短时访问**：原文仅 `reviewer`/`privacy_officer` 可凭不超过 300 秒的
  一次性授权读取，每次读取写入审计。

## 不变量

1. 同一幂等键的写操作只生效一次；同一孩子同一正文全库只保留一份。
2. 审计日志只追加，逐条哈希链可校验，覆盖式修改必然暴露。
3. 进入封存清单的信件在封存时点必须：复核通过 + 上行授权有效。
4. 公开展示必须能拿出展示时刻有效的授权快照，否则拒绝登记。
5. 直接身份与正文永远不出现在业务响应与审计明细中。
